# Personal Profile App – Flutter & Dart

A personal profile application developed using **Flutter and Dart**, featuring a hardcoded demo login system for two users. After successful login, the app dynamically displays the logged-in user's profile, including personal information, profile picture, introduction, About Me section, and contact details.

This is my first Flutter project, developed to strengthen my understanding of mobile application development, Flutter's widget-based architecture, and navigation management.

### ✨ Key Features
- Welcome Screen with Fade & Opacity Animations.
- Hardcoded Login System for Two Users.
- Dynamic User Profiles Based on Login Credentials.
- Individual Profile Pictures for Each User.
- Personal Information and About Me Sections.
- Interactive Contact Me Dialog.
- Smooth Screen Transitions and Animations.
- Responsive and Mobile-Friendly UI.

### 📱 Flutter Concepts Implemented
- Scaffold, AppBar and SafeArea.
- Container, Column, Row and other fundamental widgets.
- Drawer and Bottom Navigation Bar concepts.
- Navigator Stack and Screen Navigation.
- `Navigator.push()` – Navigate to another screen.
- `Navigator.pop()` – Return to the previous screen.
- `Navigator.pushReplacement()` – Replace the current screen.
- PageRouteBuilder and Custom Transitions.
- Stateful Widgets and Data Modeling.
